# CDC PKD Besut — Field Operations Toolkit

Repository khusus untuk aplikasi dan alat sokongan operasi unit CDC, Pejabat Kesihatan Daerah Besut.

## Aplikasi tersedia
- [ACD Scabies v2.0](scabies/) — checklist ACD, panduan IACS 2020, data agregat kes/kontak per unit, epidemic curve, pemantauan susulan dan laporan situasi.
- [Google Form Saringan ACD Scabies (responden)](https://docs.google.com/forms/d/e/1FAIpQLSezXK5iYwu5oSj3VqE3wKO-gfeWn0nbmvKpbSLWfPT29tNXYw/viewform?usp=header) — milik akaun Google penyelaras CDC PKD Besut. Perlu Publish dan ujian akses sebelum diedarkan.

## Laporan ACD terkini (data agregat, Public)
- [Dashboard epidemiologi dan laporan ACD 21 Oktober 2026](scabies/epid/) — snapshot agregat sementara yang tidak mengenal pasti individu.
- [Fail statistik agregat yang diluluskan untuk paparan Public](scabies/data/2026-10-21-summary.json) — tiada data baris individu.
- **DILARANG** memuat naik respons mentah Google Forms, ID pesakit, nama, kod dorm/bilik, nombor kad pengenalan, atau data kontak pesakit ke GitHub Public.
- Google Sheets/Google Docs dalaman mengandungi semakan klinikal dan nota QA yang **tidak** diterbitkan di repository ini.
- Versi agregat bertarikh 21 Okt 2026 ialah snapshot manual; tidak disegerakkan secara langsung dengan Google Forms.

## Keselamatan & penggunaan
Ini merupakan bahan bantu rujukan lapangan dan draf laporan, **bukan** arahan rasmi KKM, sistem rekod pesakit atau pengganti SOP PKD/JKN. Jangan masukkan identiti atau rekod pesakit ke repository awam. Fungsi analisis sedia ada di dalam pelayar tidak disegerakkan dengan Google Form; Google Form ialah pautan luaran yang berasingan. Penggunaan dan kawalan akses bagi data sensitif hendaklah disahkan melalui saluran rasmi PKD.
